# nfch.ru — сайт ООО «Нефтебаза Черепаново»

Статический сайт без движка. Никаких сборщиков, зависимостей и JavaScript,
кроме счётчика Метрики. Правится обычным текстовым редактором.

## Структура

```
index.html         главная
requisites.html    карточка предприятия
privacy.html       политика обработки персональных данных
404.html           страница ошибки (пути от корня — см. ниже)
robots.txt
sitemap.xml
.nojekyll          отключает обработку Jekyll на GitHub Pages
assets/
  site.css         единственный файл стилей
  fonts/           Golos Text, вариативный woff2, кириллица и латиница
  img/             фотографии, иконки, логотип, favicon
```

## Деплой

Содержимое папки кладётся в корень ветки `main`.
Settings → Pages → Deploy from a branch, `main`, `/ (root)`.

Файл `CNAME` с содержимым `nfch.ru` создаёт сам GitHub при подключении
домена — при обновлении репозитория его нельзя удалять, иначе домен отвалится.

## Правки контента

Всё содержимое лежит прямо в HTML, без шаблонизатора. Шапка и подвал
продублированы в четырёх файлах: меняя их, меняйте во всех.

Цены на главной намеренно указаны как «по запросу» и ведут на телефон
отдела продаж — так же, как на боевом сайте.

Телефоны в разметке продублированы: видимый текст в формате
`8 (913) 450-48-88` и машинный в `href="tel:+79134504888"`. При смене
номера правьте оба.

## Технические заметки

**Шрифт.** Golos Text (Паратайп, открытая лицензия) лежит локально в
`assets/fonts`, вариативный woff2 с кириллическим сабсетом. Внешних
запросов к шрифтовым CDN нет.

**404.** GitHub Pages отдаёт `404.html` по любому несуществующему адресу,
включая вложенные, поэтому пути в нём указаны от корня (`/assets/...`).
Это верно для сайта на своём домене. При публикации в подпапку
(`username.github.io/repo/`) их нужно поменять на `/repo/assets/...`.

**Метрика.** Счётчик 97653958 подключён на всех страницах в конце `<body>`.

**Анкоры.** `#main`, `#neftebaza`, `#products`, `#contacts` — на них ссылается
меню со всех страниц, переименовывать нельзя без правки ссылок.

## История

Сайт был выгружен из Tilda в июне 2024, затем переработан:

- ЧПУ-адреса `/details` и `/privacy` держались на `.htaccess`, который
  на GitHub Pages не работает. Страницы стали `requisites.html` и
  `privacy.html` (`/details` был переименован в `/requisites` ещё
  на боевом сайте).
- Контент подтянут до версии боевого сайта на октябрь 2025: две позиции
  дизтоплива с ценой «по запросу» вместо фиксированной цены июня 2024,
  обновлённые показатели мощностей, сокращённое меню.
- Убраны разделы «Обратный звонок» и «Партнеры», удалены формы Tilda:
  они отправлялись на серверы Tilda и вне платформы не работали.
  Кнопки «Связаться с нами» и «Оставить заявку» ведут в раздел контактов.
- Главная и внутренние страницы переверстаны с нуля. Движок Tilda,
  jQuery и десяток её скриптов удалены полностью.

В политике конфиденциальности исправлены два дефекта исходника: адрес
сайта был указан как `cherepanovo.tilda.ws`, и таблица из раздела 6
при переносе в Tilda схлопнулась в список со склеенными подписями.
Текст политики в остальном совпадает с исходным посимвольно.
